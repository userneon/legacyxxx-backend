# LEGACY-X Reconnect Changelog

The new Reconnect module adds plugin-authenticated session persistence, online server heartbeat tracking, a private Last Played API, static server registry validation and a `css_reconnect` command. The module is intentionally separate from MatchZy, AdminPlus, AFK Manager and Community: it observes connect/disconnect state but never restarts a map, changes a team, awards progression or exposes player presence publicly.
